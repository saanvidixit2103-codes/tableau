# 🏎️ Formula 1 Race Intelligence Hub

An end-to-end interactive Formula 1 analytics suite built using Tableau Desktop and deployed live to Tableau Public. Analyzes 17 seasons, 29 international circuits, 10 constructor teams, and over 6,400 race records.

## 📊 Key Highlights & Metrics
* **Data Scale:** 17 F1 Seasons | 29 Unique Circuits | 10 Teams | 6,464 Logged Race Outcomes
* **Interactive Parameters:** Dynamic `Top N parameter` slider, `Year of Race Date`, and `Dnf Reason` filtering.
* **Core Analytics:**
  - **Driver Leaderboard:** Dynamic cumulative points ranking using interactive Top-N controls.
  - **Driver Reliability & DNF Breakdown:** Categorized failure classification (Engine, Gearbox, Electrical, Collisions).
  - **Constructor Championship Performance:** Points concentration across constructors (Red Bull Racing, Mercedes, Ferrari).
  - **Tyre Strategy Analysis:** Compound distribution and degradation analysis across Soft, Medium, and Hard tyres.
  - **Global Race Map:** Geographic density across Grand Prix host nations.
